# 연구 가설의 다양성: 진단과 계획 (2026-11-12)

상태: **제안.** 새 가설군을 실제로 돌리려면 **결과를 보기 전에** 사전등록이 먼저다. 이 문서는 사전등록이 아니다. 자격 심사 관문(PBO, 비용, 파라미터, 경제적 우위, 증거 폭)과 임계값은 건드리지 않는다.

## 1. 지금 무슨 일이 일어나고 있나 (`/health`, 2026-11-12 20:00 KST 전후)

- 폐루프 부트스트랩 심사: 후보 **9개 중 자격 통과 0, 탈락 9** (릴리스 c9b99e186 이후 `bootstrapQualification`).
- 9개 모두에 붙은 탈락 코드: `BENCHMARK_EDGE_LOST`, `DEFLATED_SHARPE_BELOW_CONFIDENCE_THRESHOLD`, `EXPECTANCY_TURNS_NEGATIVE`, `NON_POSITIVE_BUY_AND_HOLD_OUTPERFORMANCE`, `PROFIT_FACTOR_BELOW_ONE`, `REGIME_FRAGILE_EDGE`. 일부에는 `RETURN_COLLAPSE`(4개), `DRAWDOWN_EXPANDS`(2개). 즉 **후보 전부가 실제로 손실이다** (손익비 1 미만, 기대값 음수, 단순 보유보다 못함). 관문이 과하게 엄격한 것이 아니다.
- 연구의 메타 학습(`metaLearning`): 실험 18개, 설정 577개, 발견 통과 15, 홀드아웃 통과 0, **과적합률 100%**, `steeringMode=DEPRIORITIZE_EXHAUSTED`.
- 같은 메타 학습이 "소진됨"으로 적은 영역: `dataType=CLOSE`, `timeframe=INTRADAY`, `timeframe=DAILY`, `universe=FIVE`, `methodClass=RULE`. 풀이하면 **종가 기반 규칙 전략을 5개 시장에서, 일중·일봉으로 시험하는 것은 다 해 봤다**는 뜻이다.
- 같은 메타 학습의 **다음 권고: `ORDERBOOK+INTRADAY+ALL_KRW+ML`** (호가창 데이터, 일중, 전체 원화 시장, 머신러닝 방법). 이것이 2026-11-18에 판정이 나오는 사전등록 호가 연구 2차(`ML_ORDERBOOK_60M_20261111`)와 같은 방향이다.

## 2. 후보 다양성 진단

- 현재 실제 연구 실행기가 지원하는 가설군은 **세 개**뿐이다 (`scripts/research-real-market-run.js`): SMA 교차(`sma-crossover`, 9개 파라미터), RSI 평균회귀(`rsi-mean-reversion`, 3x3=9개), 돈치안 돌파(`donchian-breakout`, 5개). 모두 **봉(캔들) 가격만 쓰는 기술적 규칙**이다. 호가창, 체결 흐름, 선물 정보를 쓰는 가설군은 실행기에 없다.
- 한 번의 실행은 한 가설군만 돌린다(학습 순서로 다음 군이 정해진다). 심사된 9개는 **한 가설군의 변형일 가능성이 크다** (SMA 9칸, 또는 RSI 9칸). 어느 쪽인지는 아직 읽히지 않는다. 동반 코드 변경이 `bootstrapCandidateFamilies`(가설군별 후보 수)를 `/health`에 내보내 이를 확정한다.
- 한 가설군의 변형 9개는 서로 상관이 높아서 독립 시험이 아니다. 그래서 다중 비교 보정(DSR, PBO)이 크게 깎이는 방향으로 작용하고, 하나의 군이 실패하면 9개가 같이 실패한다 (`9 / 9`로 겹치는 탈락 코드가 그 증거다).

## 4. 지켜야 할 규칙 (어떤 새 가설군에도)

1. **사전등록이 결과보다 먼저.** 가설, 신호, 파라미터 격자, 기간(훈련·검증·홀드아웃), 비용 모델, 통과 조건, **시험 횟수 K**를 데이터를 보기 전에 문서와 커밋으로 고정한다 (호가 연구 사전등록 문서가 형식의 기준이다).
2. **다중 비교 예산.** 가설군을 하나 늘릴 때마다 K가 커지고 보정된 유의수준(`p < 0.05/K`)이 엄격해진다. 가설군 수와 격자 크기를 먼저 정하고, 홀드아웃은 한 번만 연다.
3. **관문은 그대로.** 새 가설군도 같은 자격 심사(OOS, DSR, PBO, 국면, 비용, 리그)를 통과해야 한다. 후보가 안 나온다는 이유로 기준을 낮추지 않는다.
4. **PAPER_ONLY, `liveAuthority=NONE`, `aiAuthority=ZERO_AUTHORITY`.** 다양성 확대는 연구 범위만 넓힌다. 실행 권한, 위험 한도, 자본은 변하지 않는다.

## 5. 제안하는 순서

1. (코드, 동반 변경) `bootstrapCandidateFamilies`를 `/health`에 내보내 현재 후보가 어느 가설군인지 확정한다. 표시 전용.
2. (조사, 읽기 전용) 선물 수집기가 왜 한 건도 못 저장하는지 원인을 읽는다. 원인이 호스트 네트워크나 외부 차단이면 소유자 결정 사항일 수 있다.
3. (설계) 체결 흐름 가설군(순위 2)의 사전등록 초안을 쓴다. 신호, 격자, K, 기간, 통과 조건을 정하고 독립 검토를 받은 뒤 **그 문서를 머지한 다음에** 코드를 쓴다.
4. 2026-11-18 호가 연구 2차 판정 결과를 기록하고, 통과 여부에 따라 2, 3순위의 우선순위를 다시 정한다.

## 6. 하지 않는 것

PBO, 비용, 파라미터, 경제적 우위, 증거 폭 관문의 완화. 임계값, 위험 한도, 자본, 권한 변경. 사전등록 전에 새 가설군으로 결과를 미리 보는 일(홀드아웃 엿보기). 이 문서는 어떤 가설군도 구현하거나 실행하지 않는다.
